# media/gallery/

Bilder für die Außenwirkung: Studio-Fotos, Detailaufnahmen für Marketing,
variantenübergreifende Ansichten. Dient zugleich als Fallback für
`media/variants/<id>/`.

## Dateinamen

Laufende Nummer als Präfix für die Reihenfolge, danach ein sprechender Name
in kebab-case, ohne Umlaute:

```
01-front.jpg
02-schraeg-links.jpg
```

## Nicht ins Git

Shop-Bilder in voller Auflösung gehören nicht in dieses Repository. Eine
Lösung dafür steht noch aus.
