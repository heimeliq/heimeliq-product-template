# media/process/

Bautagebuch und Prozessdokumentation: Fotos vom Baum, von der Werkstatt,
vom Bauablauf.

## Dateinamen

Laufende Nummer als Präfix für die Reihenfolge, danach ein sprechender Name
in kebab-case, ohne Umlaute:

```
01-stamm.jpg
02-zuschnitt.jpg
```

## Nicht ins Git

Bilder in voller Auflösung, die nur dem Shop dienen, gehören nicht hierher.
Eine Lösung dafür steht noch aus.
